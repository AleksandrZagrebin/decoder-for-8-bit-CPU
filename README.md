#  Decoder for 8-bit CPU

Пет-проект на тему декодировщик шестнадцатеричного машинного кода в текстовые инструкции ассемблера для учебного 8-битного процессора.

## Постановка задачи

Разработать декодировщик (decoder), который преобразует шестнадцатеричный машинный код обратно в текстовые инструкции ассемблера.

## Архитектура процессора

Процессор имеет 4 регистра: A, B, C, D. Каждый регистр хранит 8-битное значение (0-255).

## Система команд

Процессор поддерживает 7 инструкций:

| Инструкция   | Описание                           |
|--------------|------------------------------------|
| MOVI X       | Загрузить число X (0-127) в регистр D |
| ADD Rd, Rs   | Rd = Rd + Rs                       |
| SUB Rd, Rs   | Rd = Rd - Rs                       |
| MUL Rd, Rs   | Rd = Rd * Rs                       |
| DIV Rd, Rs   | Rd = Rd / Rs                       |
| IN Rd        | Ввод числа в регистр Rd             |
| OUT Rs       | Вывод числа из регистра Rs          |

## Кодировка инструкций

Каждая инструкция кодируется одним байтом (8 бит). Старший бит (бит 7) определяет тип команды:

- Бит 7 = 0 -> MOVI (7 бит под immediate)
- Бит 7 = 1 -> остальные команды

### Формат MOVI (бит 7 = 0)

0 IIIIIII

7 бит для числа (0-127)

### Формат остальных команд (бит 7 = 1)

1 OOO RR SS

- OOO - опкод команды (3 бита)
- RR - регистр назначения (2 бита)
- SS - регистр источник (2 бита)

### Таблица опкодов

| Команда       | Опкод |
|---------------|-------|
| ADD Rd, Rs    | 000   |
| SUB Rd, Rs    | 001   |
| MUL Rd, Rs    | 010   |
| DIV Rd, Rs    | 011   |
| IN Rd         | 100   |
| OUT Rs        | 101   |

### Кодировка регистров

| Регистр | Код |
|---------|-----|
| A       | 00  |
| B       | 01  |
| C       | 10  |
| D       | 11  |

## Формат входных данных

Декодировщик получает на вход шестнадцатеричные байты машинного кода:

0x0A
0x05
0x89
0xC0

Байты могут быть введены:
- по одному на строке
- в одной строке через пробел

## Формат выходных данных

Декодировщик выводит текстовые инструкции ассемблера:

MOVI D, 10
MOVI D, 5
ADD A, B
OUT A

## Ограничения

- MOVI работает только с числами от 0 до 127
- Используется только 4 регистра (A, B, C, D)
- Всего 7 инструкций
- Каждая инструкция кодируется 1 байтом
- Неподдерживаемые инструкции игнорируются

## Пример работы

Вход:

0x0A
0x05
0x89
0xC0

Выход:

MOVI D, 10
MOVI D, 5
ADD A, B
OUT A

## Технологии

- Язык: C99
- Сборка: Makefile
- Тесты: интеграционные тесты в папке tests/

## Сборка и запуск

### Сборка программы

Склонируйте репозиторий и выполните сборку:

1. Скопируйте файлы проекта на свой компьютер:
   - папку src/ с исходным кодом
   - Makefile

2. Откройте терминал в корневой папке проекта

3. Выполните команду:
   make

### Запуск программы

Интерактивный ввод:
./decoder

Вводите hex-байты по одному на строке. Для завершения нажмите Ctrl+D (Linux/Mac) или Ctrl+Z (Windows).

Ввод из файла:
./decoder < input.hex

Сохранение вывода в файл:
./decoder < input.hex > output.txt

Очистка:
make clean

## Пример полного цикла

```bash
# Создаём файл с hex-байтами
echo "0x0A" > prog.hex
echo "0x05" >> prog.hex
echo "0x89" >> prog.hex
echo "0xC0" >> prog.hex

# Декодируем
./decoder < prog.hex

# Вывод:
# MOVI D, 10
# MOVI D, 5
# ADD A, B
# OUT A
